# كاشير سدرة V5.2.1 — حزمة تحديث لنفس مستودع GitHub

**الإصدار:** 2026.11.11.3 — **الحالة:** إصدار يحتاج اختبار قبول على الموبايل قبل الاعتماد الكامل في المحل.

## ما اتغيّر

- استعراض فواتير اليوم وأمس وآخر 7 أيام والشهر الحالي ويوم أو فترة مخصصة وجميع الفواتير؛ الإجمالي لا يختفي مع خيار الجميع.
- جدول مراجعة يومية، مع زر لتنزيل Excel لأي يوم سابق، بما في ذلك الأيام المغلقة.
- صافي المبيعات يفصل عن مبيعات الآجل وتحصيلات الآجل والحركة النقدية الفعلية.
- تصحيح المكسب النظري: تكلفة شراء مجهولة أو تكلفة تاريخية غير مسجلة = مساهمة صفر في المكسب النظري، مع تنبيه صريح؛ لا يعاد تسعير الفواتير القديمة من أسعار اليوم.
- إصلاح تصدير اليومية عند وجود مرتجع، مع فصل مرتجعات الأيام السابقة وعرضها باليوم الذي حدثت فيه.
- أصناف الوزن تفتح افتراضيًا على **بالفلوس**، والأصناف المعدودة تفتح على **بالعدد**.
- سعر كميات اختياري للموزون من 125 جرام، مع اختصارات 125 و250 و500 و1000 جرام؛ الصنف واحد والمخزون واحد. يمكن بيع نفس الصنف بالطريقتين داخل نفس الفاتورة.
- Excel يفصل كمية/مبلغ البيع العادي وكمية/مبلغ بيع الكميات؛ عمليات البيع القديمة التي لا تحفظ نوع السعر توضع في أعمدة «غير مصنف قديم» بدل التخمين.
- زر إضافة صنف سريع من شاشة البيع مع فحص الأسماء والباركود المكرر.
- تعديل إداري لسعر البيع وتكلفة المخزون الحالي وسعر بيع الكميات. تسجيل وارد جديد لا يزال وحده يضيف مخزونًا ويحدّث متوسط تكلفة الشراء؛ التعديل الإداري لا يضيف مخزونًا ولا يغير فواتير سابقة.
- فواتير الآجل: حفظ صورة PNG دون إنترنت أو معاينة A4 داخل التطبيق مع زر حفظ ملف PDF مباشرة، دون الحاجة لنافذة جديدة أو للطباعة؛ طباعة الهاتف اختيارية؛ كشف حساب عميل قابل للطباعة PDF.
- إعداد زر الرجوع: مرتان خلال ثانيتين أو تأكيد الخروج؛ تنبيه خاص عند وجود فاتورة غير محفوظة. التحكم النهائي في زر إغلاق التطبيق يعتمد على نظام أندرويد والمتصفح.
- تثبيت اسم قاعدة البيانات ومعرف PWA دون أي استدعاء لحذف IndexedDB أو بيانات الموقع.

## طريقة التحديث من GitHub — دون حذف المشروع

1. **خذ نسخة Backup JSON جديدة** من الهاتف قبل أي شيء، واحتفظ بها خارج الهاتف أيضًا. احتفظ بملفات الإصدار السابق للرجوع عند الحاجة.
2. **فك ضغط ZIP على الكمبيوتر أو الهاتف**. لا ترفع ملف ZIP نفسه إلى المستودع على أنه ملف تطبيق؛ ارفع **الملفات التي بداخله**.
3. افتح Repository الحالي `sedra-cashier-v5`، وليس مستودعًا جديدًا. على الفرع الذي ينشر GitHub Pages (عادة `main`) اختر **Add file → Upload files**.
4. ارفع جميع ملفات التطبيق الجديدة إلى **جذر المستودع نفسه**، بما فيها `index.html` و`sw.js` و`version.json` وملفات `*.20261111_3.js` و`*.20261111_3.css` والأيقونات والـmanifest. وافق على استبدال الملفات بنفس الاسم، ثم **Commit changes** مرة واحدة. **لا تحذف الملفات القديمة**.
5. انتظر اكتمال نشر GitHub Pages، ثم افتح رابط الكاشير الأصلي في Chrome وأنت متصل بالإنترنت. افتح التطبيق المثبت بعد ذلك.
6. من **المزيد → التحقق من التحديث**، أو عند ظهور التنبيه، افتح النسخة الجديدة **بعد حفظ أي فاتورة مفتوحة**.
7. تأكد من ظهور رقم **V5.2.1 · 2026.11.11.3** في صفحة «المزيد». لم يتغير رابط التطبيق أو PWA ID أو اسم قاعدة البيانات `SedraCashierV5_20261108_FINAL`.

## اختبارات القبول على الهاتف قبل استخدام المحل

- افتح فاتورة قديمة من آخر 7 أيام؛ اختر «جميع الفواتير» وتأكد من ظهور الإجمالي وعدد الفواتير.
- افتح يومًا سابقًا وصدّر Excel؛ تأكد من وجود Sheets «الملخص» و«ملخص بيع الأصناف» و«المرتجعات».
- جرّب صنف وزن عادي بالفلوس، وصنف معدود بالعدد.
- من إدارة الصنف، فعّل سعر كيلو للكميات، ثم جرّب بيع نفس الصنف بـ10 جنيه وبـ125 جرام في فاتورة اختبار **قبل حفظها**؛ تأكد من الوزن والإجمالي وتراجع عن الاختبار أو سجّله في بيئة منفصلة.
- إذا احتجت تجربة حفظ فعلية، استخدم **جهاز اختبار أو نسخة قاعدة بيانات تجريبية منفصلة**، وليس معاملات المحل الحقيقية.
- جرّب تصدير فاتورة آجل PNG وPDF؛ PDF يُنشأ ويحفظ مباشرة من داخل التطبيق دون نافذة منبثقة.
- جرّب زر الرجوع مع/بدون فاتورة غير محفوظة؛ أندرويد قد يفرض الخروج في بعض الحالات.
- جرّب التشغيل Offline بعد تحميل جميع ملفات التحديث مرة واحدة مع إنترنت.
- تأكد أن الأرصدة والمديونيات والفواتير الحالية لم تتغير قبل وبعد التحديث.

## التحقق المنفذ قبل التسليم

- فحص Syntax لكافة ملفات JavaScript.
- اختبارات منطقية مع نسخة البيانات المرفوعة **في بيئة معزولة** لفلاتر اليوم والتاريخ والمكسب النظري ومرتجع فاتورة من يوم سابق.
- توليد ملف Excel متعدد الأوراق بالفعل (11 ورقة) والتحقق من بنيته كملف XLSX.
- اختبار حاسبة بيع موزون عادي وبسعر الكميات لنفس الصنف، بالإضافة إلى صنف معدود.
- **لم يتم اختبار تشغيل أندرويد الفعلي أو نشر GitHub من هذه البيئة**؛ يلزم اختبار القبول أعلاه.

## حماية البيانات

**النسخة الاحتياطية التي أرسلتها غير موجودة داخل هذه الحزمة وغير مخصصة للرفع إلى GitHub.** ملفات النشر كود تطبيق فقط. لا تستورد Backup القديم فوق بيانات فيها فواتير أحدث. ليس هناك مزامنة تلقائية بين الأجهزة، والنشر على GitHub لا ينقل قاعدة البيانات من جهاز إلى آخر.
