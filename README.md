# كاشير سدرة V5 — إصلاح تحديث النسخة المثبتة (10 نوفمبر 2026)

## سبب المشكلة
الـService Worker السابق كان يقدّم ملفي JavaScript وCSS من Cache قديم (Cache-first) حتى بعد تحديث الملفات على GitHub. النسخة المثبّتة لذلك كانت تعرض شاشة أقدم من Chrome.

## ما تغير
- تم إصدار ملفات مرقمة بالإصدار بدل أسماء ثابتة للواجهة (`app.20261110_1.js` و`styles.20261110_1.css` و`v5-upgrade.20261110_1.js`).
- أصبح الـService Worker من نوع Network-first لجميع ملفات البرنامج عند وجود إنترنت، مع نسخة احتياطية Offline.
- فحص تحديث عند تشغيل النسخة المثبتة ومرة عند العودة للتطبيق، وزر «التحقق من التحديث» ورقم إصدار في صفحة «المزيد».
- **لا يحدث إعادة تحميل قسرية أثناء تحرير فاتورة**؛ يظهر خيار تحديث بعد إتمام العمل.
- لم تتغير قاعدة البيانات ولا معرف الـPWA ولا ملف استيراد JSON ولا واجهة الصفحات ووظائف البيع والآجل والجرد.
- لا تُرفع بيانات الجرد الشخصية إلى GitHub.

## النشر
1. صدّر Backup JSON من V5 الحالي قبل التحديث إن أمكن.
2. لا تمسح أي تطبيق ولا بيانات Chrome.
3. فك ملف ZIP وارفع **كل الملفات معًا إلى جذر Repository `sedra-cashier-v5` الحالي**، واستبدل الملفات المتطابقة، دون إنشاء Repository جديد.
4. انتظر اكتمال GitHub Pages (Settings > Pages)، وافتح `https://adham253.github.io/sedra-cashier-v5/` على Chrome مرة وأنت متصل.
5. افتح أيقونة الكاشير المثبّتة. إذا ظهرت رسالة تحديث، أنهِ أي فاتورة مفتوحة واضغط «فتح النسخة الجديدة». أو افتح «المزيد > التحقق من التحديث».
6. في «المزيد» تأكد أن رقم الإصدار: **V5 · 2026.11.10.1**. إذا ظل قديمًا، اقفل التطبيق من التطبيقات الحديثة وافتحه مع الإنترنت.
7. اختبر فاتورة تجريبية وميزة المكسب النظري قبل استخدام بيانات حقيقية.

## حماية البيانات
هذه الحزمة لا تستدعي indexedDB.deleteDatabase أو localStorage.clear أو مسح بيانات الموقع، ولا تغير اسم `SedraCashierV5_20261108_FINAL`. تنظيف Cache يقتصر على اسم تطبيق الكاشير `sedra-pos-v5-` ولا يحذف Cache الجرد.

## التحقق
- التطبيق يفتح على المتصفح والتثبيت من المسار نفسه `https://adham253.github.io/sedra-cashier-v5/`
- تظل ميزة العمل بدون إنترنت متاحة بعد زيارة الإصدار الجديد مرة واحدة متصلًا.
- استيراد نفس JSON الخاص متوافق؛ لا تعيد الاستيراد لو عندك فواتير حالية.

**ملحوظة:** نجاح تثبيت التطبيقين على نفس موبايلك يحتاج اختبارًا فعليًا؛ تحديث الـService Worker لا يغير هوية PWA الحالية.
